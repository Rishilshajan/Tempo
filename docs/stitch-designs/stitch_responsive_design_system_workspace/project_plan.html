DELEGATION LESSON · PROJECT PLAN

Agentic Task Manager

A task manager that manages the list with you — watching for slippage, protecting your priorities, and handing you a clear plan each morning.

👤 developer@levich.co 📅 2026-08-30 ✅ Planning complete

1Vision

An agentic, AI-powered personal task manager for juggling personal, financial, and multi-startup work at once — where important things stop silently sliding to "tomorrow."

The distinctive idea: the tool is a delegation engine for your own life — it surfaces where your time is leaking so you can offload, automate, or drop, and redirect effort to what matters.

2Success Criteria

After ~2 weeks of use:
  • You add tasks with almost no friction.
  • You trust the morning briefing enough to drop your mental backup list.
  • Nothing important silently slips — the agent catches it first.
  • The tool shows where your time is leaking so you can reclaim it.

3The Core Problem

Google Tasks is too simple for many-things-at-once. Important tasks silently slide (+1, +2, +3 days) and complexity snowballs; adding a task only captures a header; one flat screen doesn't reflect how things actually matter; and there's no warning when a new task collides with something important.

8Visual Design — Palettes & Font

Strategy: the 60-30-10 rule — calm base (~60%), supporting tone (~30%), energizing accent (~10%) for action items. Green blends calm + energy; "urgent" is a warm coral, not alarm-red. Font: Figtree (friendly, legible, modern) across all palettes.

9Delegation Growth Reflection

What grew

  • Shifted from feature-first to judgment-first.
  • Reasoned the agent should flag forgotten dependencies — machine covers a human weakness.
  • Invented the "importance = my labels + the structure" split.
  • Added auditability — mature trust-calibration.
  • Reframed the product as a delegation engine for your life.

Growth edge (next lessons)

The instinct so far is to add — great ideas, fast. The next muscle is cutting and scoping: deciding what not to build in v1 (Discernment), and specifying/checking precisely (Description, Diligence).
